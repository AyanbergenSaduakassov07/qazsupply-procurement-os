# F05. Financing and insurance referrals (future)

| Field | Value |
|---|---|
| User | CFO, supplier |
| Phase | 6 (M8) |
| Dependencies | Partner banks/insurers (sandbox), consent + data-sharing log, C10, C12 |
| Regulatory flag | HIGH: AFR (Agency for Regulation and Development of the Financial Market) licensing; referral vs intermediation (UNVERIFIED, counsel) |

**Job:** "Get trade finance or cargo insurance quotes without re-entering data."
**Flow:** user opts in -> chooses data to share -> partner receives application -> partner quotes -> shown in RFQ/shipment views.
**Acceptance:** partners decide; AI makes no credit or coverage decision; consent revocable; sandboxed flow end to end.
**AI vs deterministic:** none in decisions; prefill deterministic.
