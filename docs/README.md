# docs/

| Folder | Contents |
|---|---|
| `adr/` | Architecture decision records. One file per decision: `NNNN-title.md` (context, decision, consequences). |
| `specs/` | One spec per capability (output of `to-spec`): user, flow, acceptance criteria, data, AI-vs-deterministic split, human gate. |
| `prompts/` | The ordered prompt pack M0 to M9. |
| `runbooks/` | Ops: incidents, data-source outages, restore drills. |
| `compliance/` | Data sources and licences, legal notes, privacy and retention. |
| `research/` | Primary-source research notes. |
| `design/` | Personas, journeys, token tables, motion spec, prototypes. |
| `security/` | Threat models (STRIDE), AI-security reviews, pen-test plans. |
