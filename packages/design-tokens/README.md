# packages/design-tokens

Three-layer design tokens (primitive -> semantic -> component). M0 ships the primitive layer only.

**Public interface:** `@qazsupply/design-tokens/tokens.css` exposes `--qs-frost`, `--qs-ink`, `--qs-tengri`, `--qs-gold`, `--qs-risk`, `--qs-ok`.

**Rules:** colors come from `CLAUDE.md`. Contrast notes and deviations: `docs/design/design-system.md`. Semantic layer, dark mode, type scale: M1.
